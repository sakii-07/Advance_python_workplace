1. What is Multithreading?
Ideal Answer

Multithreading is a technique where multiple threads execute within a single process simultaneously.

A thread is the smallest unit of execution. All threads of a process share the same memory, resources, and variables but execute independently.

Multithreading improves application responsiveness and is mainly used for I/O-bound tasks.

Real-world Example

A web browser:

One thread downloads data.
One thread renders the webpage.
One thread plays audio/video.

All work simultaneously.

Follow-up Questions

Q1. What is a thread?

Q2. Do threads share memory?

Yes.

8. What is join()?
Ideal Answer

join() waits until the thread finishes execution.

Example

t.start()
t.join()

print("Completed")

Without join(), the main thread may finish before the worker thread.

Follow-up

Can join() accept timeout?

Yes.

t.join(5)
9. What happens if join() is not used?
Ideal Answer

The main thread does not wait for child threads.

The program may terminate before child threads complete.

Follow-up

Is join() mandatory?

No.

Only when synchronization is needed.

10. What is the Global Interpreter Lock (GIL)?
Ideal Answer

The GIL is a lock in CPython that allows only one thread to execute Python bytecode at a time.

Because of GIL:

CPU-bound threads cannot execute Python code in true parallel.
I/O-bound threads still benefit because they release the GIL while waiting.
Real-world Example

Two threads calculating large prime numbers

Only one thread executes Python bytecode at a time.

Follow-up

Does Python support true parallelism?

For CPU-bound tasks, use multiprocessing.

11. What is Synchronization?
Ideal Answer

Synchronization ensures that only one thread accesses a shared resource at a time, preventing inconsistent data.

Example

Two threads updating the same bank balance.

Without synchronization:

Balance may become incorrect.

Follow-up

Which object provides synchronization?

Lock.

13. What is Race Condition?
Ideal Answer

A race condition occurs when multiple threads modify shared data simultaneously, leading to unpredictable results.

Example

Two ATM machines withdraw money at the same time from the same account.

Follow-up

How to avoid it?

Using Lock.

14. What is Deadlock?
Ideal Answer

Deadlock happens when two or more threads wait for each other indefinitely, and none can proceed.

Example

Thread A holds Lock1 and waits for Lock2.

Thread B holds Lock2 and waits for Lock1.

Both wait forever.

Follow-up

How can you prevent deadlock?

Acquire locks in a consistent order.
Keep critical sections short.
Avoid nested locks when possible.
Use timeouts when acquiring locks.

18. Can multiple threads modify the same variable?
Ideal Answer

Yes.

Since threads share the same memory, they can access and modify the same variables.

This can cause race conditions if not synchronized.

Follow-up

How do you make it safe?

Use Lock or other synchronization primitives.
