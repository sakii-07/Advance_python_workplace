1. What is Pandas?
Ideal Answer

Pandas is an open-source Python library used for data manipulation and data analysis.

It provides powerful data structures like:

Series (1-dimensional)
DataFrame (2-dimensional)

It allows us to:

Read data from different files
Clean data
Filter data
Transform data
Merge datasets
Perform statistical analysis
Export processed data

It is built on top of NumPy, so it is fast and efficient.

Real-world Example

Suppose a company has customer data stored in an Excel file.

Using Pandas we can:

Remove duplicate customers
Fill missing values
Find total sales
Generate reports
Follow-up Questions

Q: Why is Pandas faster than normal Python loops?

Answer:

Because Pandas uses NumPy internally, which performs operations in optimized C code instead of Python loops.

2. What is a Series?
Ideal Answer

A Series is a one-dimensional labeled array.

It stores:

values
index

Example

import pandas as pd

s = pd.Series([10,20,30])

Output

0 10
1 20
2 30

Think of it as one column of an Excel sheet.

Follow-up

Difference between list and Series?

List	Series
No index labels	Has index
Python object	Pandas object
Less powerful	Supports vectorized operations
3. What is a DataFrame?
Ideal Answer

A DataFrame is a two-dimensional labeled data structure.

It consists of:

rows
columns

Each column is a Series.

Example

df = pd.DataFrame({
    "Name":["A","B"],
    "Age":[20,25]
})

Think of it as an Excel sheet or SQL table.

Follow-up

Can DataFrame contain different data types?

Yes.

Example

Name -> string

Age -> integer

Salary -> float

Active -> boolean

7. How do you filter data?
Ideal Answer

Use boolean indexing.

Example

df[df["Age"] > 25]

Multiple conditions

df[(df["Age"]>25) & (df["Salary"]>50000)]
Follow-up

Why use & instead of and?

Because Pandas works element-wise on Series. Python's and works only with single boolean values.

Follow-up

When should you use dropna() instead of fillna()?

Use dropna() when missing rows are very few and not important. Use fillna() when you want to preserve the data.

12. Difference between apply(), map(), and applymap()?
Ideal Answer

map()

Works only on a Series.

df["Gender"].map({
    "M":"Male",
    "F":"Female"
})

apply()

Works on Series or DataFrame.

df["Age"].apply(lambda x:x+1)

applymap()

Works on every element of a DataFrame.

df.applymap(str)
Follow-up

Which is faster?

Vectorized operations are faster than apply() because they use optimized underlying implementations.

18. What is vectorization?
Ideal Answer

Vectorization means performing operations on an entire Series or DataFrame at once instead of looping through each element.

Example

Instead of

for i in df["Age"]:

Use

df["Age"] + 5

Vectorized operations are faster because they rely on optimized NumPy implementations.

Follow-up

Why avoid loops in Pandas?

Loops are slower in Python, while vectorized operations are optimized and easier to read.

20. How do you save a DataFrame?
Ideal Answer
df.to_csv()

df.to_excel()

df.to_json()

df.to_sql()

df.to_parquet()

Example

df.to_csv(
"output.csv",
index=False
)

index=False prevents the DataFrame index from being written as a separate column.

Follow-up

Why use index=False?

By default, Pandas writes the index to the output file. If the index is not meaningful, index=False keeps the exported file clean.

Common Advanced Follow-up Questions
1. Why is Pandas built on NumPy?
NumPy provides efficient array operations.
Pandas adds labels, indexing, missing-value handling, and rich data manipulation features on top of NumPy.
2. Which file format is fastest?
Parquet → Fastest for analytics, compressed, preserves data types.
CSV → Human-readable and widely supported, but larger and slower.
3. Why avoid iterrows()?

Because it iterates row by row in Python, making it much slower than vectorized operations. Prefer vectorized methods, apply(), or itertuples() when iteration is unavoidable.

4. Difference between apply() and vectorization?
Vectorization: Faster, uses optimized NumPy operations.
apply(): More flexible for custom logic but generally slower.
5. How do you improve Pandas performance?
Use vectorized operations instead of loops.
Avoid iterrows() when possible.
Read only required columns with usecols.
Specify dtype while reading large files.
Use categorical (category) data types for repetitive strings.
Prefer Parquet over CSV for large datasets.
Use merge() efficiently and avoid unnecessary copies.
